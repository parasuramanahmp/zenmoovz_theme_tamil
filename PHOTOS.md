# ZENMOOVZ photo shot list

Put your real photos in these folders. File name = what is written below. Nothing else in the code needs to change.
Until an exact product photo exists, the store uses a locally stored product-type photo from `public/products/_stock/` (see `src/data/stock.js`). Your own `<id>.jpg` file always takes priority over this fallback, so you can replace each generic image with the exact brand/SKU photo later.

**Tips:** products on a plain white or light background, square (1000×1000 or bigger), JPG. Keep each file under about 200 KB.

## 4. Anatomy photos (feature hotspots on bats and rackets): `public/products/`
The dark "Know your gear" viewer on the HOME page (cricket = product 9, badminton = product 25) shows pulsing dots on the product. It looks best with a studio photo on a near-black background.

- File: `<id>-anatomy.jpg`, landscape 1600×1000, the product **lying horizontally, handle on the LEFT**, centred, with space around it.
- If it does not exist, the normal product photo is used on a white panel, so nothing breaks.
- Dots are placed with percentages in `src/data/anatomy.js`. If your photo is framed differently, open the home page with `?calibrate=1` (open `/?calibrate=1`), click where each dot should go, and paste the JSON it prints into `HOTSPOT_OVERRIDES`.
